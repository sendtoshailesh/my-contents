## Installation

### Basic Setup (Keyring Primary, No Cloud)

```bash
pip install -r requirements.txt

# This installs everything including keyring (primary secrets)
# No Azure subscription required
```

### Optional: Cloud Services (LLM + Key Vault)

```bash
# Already included in requirements.txt:
# - azure-identity (for Key Vault fallback)
# - azure-keyvault-secrets (for Key Vault access)
# - anthropic (for direct Claude API)
# - openai (for direct OpenAI API)

# Just set environment variable:
export AZURE_KEYVAULT_NAME="kv-content-studio-xxxxx"
```

### Development Setup (with Code Quality Tools)

```bash
pip install -r requirements.txt
pip install pre-commit

# Setup pre-commit hooks
pre-commit install
```

## Troubleshooting

**Issue**: `ModuleNotFoundError: No module named 'keyring'`  
**Solution**: `pip install keyring`

**Issue**: `stale path: ./.venv` with pyenv or other env managers  
**Solution**: Use `python -m pip install ...` instead of `pip install`

**Issue**: Azure SDK modules not found  
**Solution**: Azure SDKs optional. Only needed if using Key Vault fallback. Install with:  
```bash
pip install azure-identity azure-keyvault-secrets
```

**Issue**: Streamlit mermaid not rendering  
**Solution**: Update Streamlit: `pip install --upgrade streamlit`

## Update Flow

```bash
# Check for updates

# Update specific package

pip install --upgrade -r requirements.txt

# Create locked requirements (optional)

```

## Clean Install (Start Fresh)

```bash
# Remove venv
rm -rf .venv

# Recreate
python3.11 -m venv .venv
source .venv/bin/activate

# Fresh install
pip install --upgrade pip
pip install -r requirements.txt

# Verify
python -c "import keyring, fastapi, streamlit; print('✓ All installed')"
```
